# Translation status

See where every language stands, page by page and across the site.

- **Translations** sidebar on an item:
  - every language of the site, named as the CMS names it: published, out of date, draft, or not translated;
  - per language, how many translatable fields are translated, and which are still empty, word for word the
    source, or changed in the source since;
  - the languages the item isn't in yet, with where to add them: the CMS's own More > Translate.
- **Translations** view (Extensions in the navigation rail):
  - totals and a bar per language: up to date, draft, out of date, not started;
  - every page, filterable by language and searchable, the most actionable first.

Works with any Optimizely CMS (SaaS) instance and needs nothing from the site: a CMS API client for the sidebar
(and drafts in the view) and the Optimizely Graph single key for the view. It only reads.
